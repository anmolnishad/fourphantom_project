# Money Harvest

Money Harvest is a Next.js + TypeScript financial-literacy application.

## Main parts
- Frontend: `src/app` and `src/components`
- Backend API routes: `src/app/api`
- Database schema: `prisma/schema.prisma`
- Seed data: `prisma/seed.ts`
- AI chat endpoint: `src/app/api/chat/route.ts`
- Certificate endpoints: `src/app/api/certificates/`

## Notes
- Local environment files and the local SQLite database are intentionally excluded from this GitHub upload.
- Configure the required environment variables and database URL in your deployment environment before running the app.
- Do not commit API keys, passwords, private tokens, or personal database files.
